# mahaSTRIDE Project Tracker

A comprehensive project management and tracking system for the mahaSTRIDE initiative spanning 10 weeks across 7 universities.

## Features

- 📊 **Dashboard**: Real-time project overview with key metrics
- 🏛️ **University-wise Tracking**: Monitor progress for each of the 7 universities
- ✅ **Task Management**: Update and track task statuses
- 📚 **Framework Analysis**: Detailed analysis of SAMARTH, NEP, AEGIS, and IKS frameworks
- 📈 **Reports & Analytics**: Generate insights and export data
- 🎯 **Progress Visualization**: Interactive charts and heatmaps

## Technology Stack

- **Frontend**: Streamlit
- **Backend**: Python
- **Database**: SQLite with SQLAlchemy ORM
- **Visualization**: Plotly, Pandas
